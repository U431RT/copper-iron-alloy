# 铜铁合金 / Copper-Iron Alloy

Minecraft 模组：铁铜合金、钢金、改性白钻三条材料线，配套工具、盔甲、建筑方块与容器。

- 创意、数值与美术方向：**U431RT**
- 代码与资源生成：**AI**

## 支持版本

| MC 版本 | 加载器 | 说明 |
| --- | --- | --- |
| 26.1.2 | NeoForge 26.1.2.78 | 完整内容 |

群峦（TFC）版本仍在开发中，完成后另行发布。

## 内容

- **铁铜合金**：3 粗铜 + 1 粗铁 → 混合物 → 合金锭；工具盔甲介于铜与铁之间；剪刀、三种桶、奶桶；12 种建筑方块
- **钢金**：铁 + 金锭 + 木炭，高炉冶炼；工具带隐藏效率/时运/抢夺；盔甲使猪灵中立；块、砧、门、灯、打火石
- **改性白钻**：催化剂 → 待激发宝石 → 高炉；工具合成自带附魔；盔甲提供移速/潜行/生命/交互距离
- 三个进度与独立创造栏

## 构建

需要 JDK 25 与本地 Minecraft 26.1.2 客户端库（脚本会自动在 `.minecraft/libraries` 里找依赖）：

```bash
bash build.sh
```

产物：`build/copper_iron_alloy-*.jar`；贴图与数据由 `tools/` 下的 Python 脚本生成。
